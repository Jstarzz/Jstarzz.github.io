# about

I'm a developer from the Bahamas. Most of my time goes into problems where the data is messy and the answer isn't in a tutorial — remote sensing, model pipelines, and the unglamorous glue that turns a notebook into something someone else can run.

My final-year project at CFBC became ASI (Aqua Satus Invenio), a machine learning approach for detecting floating sargassum in satellite imagery. Sargassum wrecks Caribbean coastlines every year, and knowing where it is before it lands is genuinely useful. I've also spent time interning as a backend developer, building a streaming distribution service that fans a single source out to multiple platforms at once.

Lately I've been building developer tooling — an MCP server for eBay search, a homelab I maintain like production, and WindUI, an open source UI library that other people build on top of.
